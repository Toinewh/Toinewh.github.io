Ordo — Assistance

Ordo présente l’ordo liturgique sur l’iPhone et l’iPad, jour après jour, et accompagne le prêtre dans la célébration de la messe : les fêtes et leurs préséances, les intentions de messe et leur registre, les lieux où il célèbre.

Comment importer un ordo ?

Dans l’onglet Ordo, sur la vue des années, touchez le bouton +, puis choisissez le fichier de l’ordo : un PDF, un fichier texte ou Markdown. Les ordos importés se retrouvent dans l’onglet Sources ; quand plusieurs donnent une fête le même jour, celle qui l’emporte selon les rubriques est affichée.

Comment reprendre mon registre d’intentions ?

Dans l’onglet Intentions, le menu … propose « Importer un registre CSV… ». Si Ordo ne reconnaît pas toutes les colonnes du fichier, il vous demande à quoi correspond chacune avant de rien enregistrer.

Mes données sont-elles sauvegardées ?

Ordo fait des instantanés de vos données sur l’appareil, avant toute action qui remplace ou efface quelque chose. Avec iCloud, elle les synchronise aussi entre vos appareils et en garde des sauvegardes. Tout se règle dans l’onglet Sources, section « iCloud et partage » ; « Sauvegardes » permet de tout restaurer, ou le registre seul, après un aperçu.

Comment passer mes données sur un autre appareil ?

Avec le même compte iCloud et la synchronisation activée, l’autre appareil les reçoit de lui-même. Sinon, « Partager des données… », dans la même section, prépare un fichier avec les données choisies ; sur l’autre appareil, ouvrez-le avec Ordo pour l’ajouter à ses données ou les remplacer.

Les anniversaires de mes contacts n’apparaissent pas

Ordo lit vos contacts avec l’accès que vous lui avez accordé. Pour le modifier, ouvrez Réglages sur l’appareil, puis Apps, Ordo, Contacts.

Le lieu où je célèbre n’est pas reconnu

Ordo reconnaît un lieu enregistré par la position de l’appareil, si vous le lui permettez. Pour le vérifier, ouvrez Réglages, puis Apps, Ordo, Position, et choisissez « Lorsque l’app est active ».

Poser une question ou signaler un problème

Ouvrir un ticket sur GitHub (un compte GitHub gratuit est nécessaire). Décrivez ce que vous avez fait et ce que vous avez vu, sans le texte des intentions ni le nom de ceux qui les ont demandées : le ticket est public.

Confidentialité

Ordo ne collecte aucune donnée. Voir la politique de confidentialité.
